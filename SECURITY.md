# Security

This boot-time software includes a narrowly guarded write to the misc command field. Report unintended storage writes, verification bypasses, unsafe handoffs or owner-data disclosures privately.

Maintenance targets the current development branch/current commit. There are no release/tag support commitments or supported release series.

Submit sensitive reports through GitHub private vulnerability reporting. The maintainer will enable and test that facility before public release; this document does not assert that it is currently enabled or tested. Do not publish sensitive details in an issue. If the private entry is unavailable, wait for its activation.

通过 GitHub 私密漏洞报告提交；维护者会在公开前启用并测试。支持范围为当前开发分支／当前提交，不承诺不存在的 release/tag。
